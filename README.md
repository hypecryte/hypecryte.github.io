# Что представляет из себя проект

---
Я решил разбить задачу на отдельные секции, в которых и провожу демонстарцию вёрстки.
Все компаненты реализованы с учётом возможности добавления реализованных компанент и их переиспользования:
# 1. Секция текста

---
В данной секции я добваил кнопки, для переключения между состояниями окна для текста. 
В каждом состоянии отображается набор форматирования, демонстрирующий работу с тем или иным форматом
# 2. Секция кнопок

---
В задаче было указано сверстать по макету набор кнопок в разных состояниях. Используя состояния 
были созданы се кнопки с учётом стилей для каждого из состояний 
# 3. Секция схемы

---
Долго думал как реализовать блок-схему, но самое просто, что придумал - это сделать `.svg` схему
в Flowcharts.io
# 4. Секция витрины

---
В данной секции сделал витрину. Так как не было указано "по макету" или "аналогично тому что в задаче"
сделал свою витрину
# 5. Секция модалки и черной страницы

---
Оставшиеся задания решил объединить в одну секцию. 
- Чёрная кнопка перенаправляет на сломанную
страницу "Black-page", которую я починил и доработал, чтобы она загружалась быстрее, работала
лучше и при этом выглядела приемлемо
- Кнопка для модалки, открывает модальное окно с формой, которая была сделана на основе задания
- Кнопка дизайнера - кнопка из задания "Красота", сделанная по макету дизайнера
- Анимированный чек-бокс - кнопка из задания "Красота". Полностью реализовать не получилось, поэтому сделал максимально похожую
